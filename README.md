# GamifyLeet

![logo](.assets/logo.png "Gamify Leet")

A mono-repo app to make Leetcoding fun again, using DragonBall progression system,more progression system soon.
Made using turbo-repo, tRPC, vite, React.

# Start Local MongoDB:

docker-compose up -d
